# Portfólio profissional — LinkedIn

Abra `index.html` no navegador para visualizar.

## Publicar
- GitHub Pages: envie a pasta para um repositório e ative Pages.
- Netlify/Vercel: arraste a pasta ou conecte o repositório.
- LinkedIn: coloque a URL publicada na seção **Destaques** e/ou no campo de contato.

## Personalização
No `index.html`, substitua os dois links `href="#"` no bloco de contato pelos seus links reais de LinkedIn e GitHub.
